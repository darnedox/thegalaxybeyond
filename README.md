# The Galaxy Beyond

A galaxy exploring, mining and building game designed by David Jr.

Play: https://darnedox.github.io/thegalaxybeyond/

Online play: one player clicks "Host a game" and shares the 4 digit lobby code; friends click "Join" and type it. No accounts needed.

Music: "Shine", "Sphere" and "High Tide" by Creo.

Developers: edit files in `src/`, then run `./build.sh` to rebuild `index.html`.
